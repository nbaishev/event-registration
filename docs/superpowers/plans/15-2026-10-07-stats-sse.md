## Contract / Acceptance criteria

- GET `/api/events/{event_id}/stats/stream`: cookie auth → missing 404 → ownership 403 → DRAFT 409 EVENT_NOT_PUBLISHED; PUBLISHED/finished/CANCELLED разрешены. Без CSRF; errors до streaming используют ErrorResponse.
- Content-Type text/event-stream, Cache-Control no-store; event frame `event: stats_changed\ndata: {}\n\n`; heartbeat comment `: heartbeat\n\n` каждые 15s. Нет counters, ticket/email, event IDs других events или replay IDs в payload.
- Auth/state checks внутри явно ограниченного Session context; stream не использует yield DatabaseSession dependency, lifetime которой может совпасть со stream. Получает primitive user/event IDs, закрывает session до возврата StreamingResponse. Existing CurrentUser не подключать так, чтобы auth session удерживалась на stream.
- Subscribe до возврата headers; disconnect/cancellation finally снимает subscription. Lifespan shutdown закрывает subscriptions и loop reference.
- Register/reactivate, registration cancel, promotions, actual capacity change, check-in: один coalescible signal на Event после успешного внешнего commit. Promotion helper не publish/commit; cancellation+promotion и capacity+promotion дают один сигнал. Rollback/failure/no-op capacity не публикуют.
- Sync publish использует loop.call_soon_threadsafe; queue operations только на loop. На подписчика bounded queue maxsize=1: pending signal coalesces, slow consumer не блокирует transaction и не накапливает бесконечную очередь.
- Publish failure после commit не превращает committed business success в HTTP failure; сигнал best-effort, snapshot восстанавливается refetch при reconnect. Infrastructure failure логируется без participant data.
- Nginx отдельный stats/stream location: proxy_buffering off, proxy_read_timeout 60s, прежние proxy headers. Backend workers=1 сохраняется.

## Files / interfaces

Create `backend/app/events/broadcaster.py`, `stream.py`, `backend/tests/unit/test_stats_broadcaster.py`, `backend/tests/integration/test_stats_stream.py`; modify main.py, events/router.py, registrations/service.py/checkin.py, capacity commit branch events/service.py, infra/nginx/default.conf. Regenerate API schema.
Produces app-owned `StatsBroadcaster`: `publish(event_id: UUID) -> None` (thread-safe), loop-only `subscribe(event_id: UUID) -> asyncio.Queue[None]`, `unsubscribe(event_id, queue) -> None`, startup/shutdown; dependency `get_stats_broadcaster(request: Request) -> StatsBroadcaster`. Inject broadcaster into changed outer use-cases via optional keyword argument `broadcaster: StatsBroadcaster | None = None`; routers передают app instance, direct callers/tests остаются совместимы. No global session events/hooks.

## Review Focus / Test strategy

Unit: threadpool publish, event isolation, coalescing, unsubscribe/shutdown; deterministic fake scheduling, без sleep для business timing. Integration: all five mutation sources, commit visibility через другую Session, rollback silence, no-op silence, auth/lifecycle и pool connection release while stream open. Streams читать реальным async HTTP transport/server с явным timeout и teardown; не использовать буферизующий бесконечный TestClient read.
Transport E2E `frontend/e2e/stats-stream.spec.ts` через existing fixtures: browser fetch/reader с cookies и AbortController через Nginx, получить frame до закрытия stream, wrong owner rejection. Test subscriptions установить до mutation; backend pool counters доказывают release в integration.
